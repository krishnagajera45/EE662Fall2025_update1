Usage Guide
===========

This document provides a comprehensive guide on how to use the WSN protocol simulation, including running simulations, generating plots, and analyzing results.

Running a Simulation
--------------------

Basic Simulation
~~~~~~~~~~~~~~~~

To run a single simulation:

.. code-block:: bash

   python3 wsnlab/data_collection_tree.py

This will:
* Create nodes according to ``SIM_NODE_COUNT`` in config
* Run for ``SIM_DURATION`` seconds
* Generate CSV log files
* Show visualization window (if ``SIM_VISUALIZATION = True``)

Output Files
~~~~~~~~~~~~

After running, you'll find these CSV files in the project directory:

**Core Logging Files:**
* ``registration_log.csv`` - Node join times and registration delays
* ``packet_delays.csv`` - Packet delivery delays with timing breakdown
* ``packet_paths.csv`` - Complete packet routing paths
* ``packet_routes.csv`` - Packet routing decisions
* ``role_changes.csv`` - Node role transition events

**Network State Files:**
* ``network_snapshots.csv`` - Network state snapshots at specific times
* ``connectivity_over_time.csv`` - Network connectivity statistics over time
* ``topology.csv`` - Network topology information (if generated)

**Recovery and Failure Files:**
* ``recovery_events.csv`` - Node failure and recovery events (if enabled)
* ``orphan_events.csv`` - Orphan node events (if enabled)
* ``recovery_time.csv`` - Recovery time statistics (if generated)

**Energy and Power Files:**
* ``node_power_levels_over_time.csv`` - Power levels for all nodes over time
* ``node_power_levels.csv`` - Final power levels per node (if generated)
* ``averagePower_by_time.csv`` - Average network power over time (generated by analysis)
* ``NodePower_levels.csv`` - Current power levels for all nodes (generated by analysis)
* ``nodePower_over_time.csv`` - Detailed power progression per node (generated by analysis)
* ``totalPower_by_time.csv`` - Total network power over time (generated by analysis)

**Cluster and Neighbor Files:**
* ``clusterhead_distances.csv`` - Distances between cluster heads (exported periodically)
* ``neighbor_distances.csv`` - One-hop neighbor distances (exported periodically)
* ``multihop_neighbor_table.csv`` - Multi-hop neighbor information
* ``cluster_members.csv`` - Cluster membership information

**Distance and Topology Files:**
* ``node_distances.csv`` - Pairwise distances between all nodes
* ``node_distance_matrix.csv`` - Distance matrix for all nodes

**Other Files:**
* ``packet_log.csv`` - General packet logging (if enabled)
* ``wsn_log_<timestamp>.log`` - Timestamped log file with detailed simulation events (if ENABLE_LOG_FILE is True)

See the :doc:`overview` documentation for detailed descriptions of each file's structure and columns.

Batch Simulations
-----------------

Running Multiple Simulations
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To run 10 simulations and collect statistics:

.. code-block:: bash

   python3 run_batch_simulations.py

This will:
* Run 10 simulations sequentially
* Save results from each run in ``batch_simulation_results/run_XX/``
* Generate aggregated statistics
* Create ``aggregated_statistics.json`` with averages

Output Structure
~~~~~~~~~~~~~~~~

::

   batch_simulation_results/
   ├── run_01/
   │   ├── registration_log.csv
   │   ├── packet_delays.csv
   │   └── ...
   ├── run_02/
   │   └── ...
   ├── ...
   ├── individual_run_stats.json
   └── aggregated_statistics.json

The aggregated statistics include:
* Average join time (mean, std dev, min, max)
* Average packet delay (mean, std dev)
* Average number of clusters (mean, std dev)

Plot Requirements
~~~~~~~~~~~~~~~~~

Some plots require specific data:

* **Batch Simulation Averages**: Requires running ``run_batch_simulations.py`` first
* **Packet Loss vs Join Time**: Requires ``packet_loss_analysis.json`` (see below)

Packet Loss Analysis
--------------------

To analyze packet loss impact, you need to run simulations with different loss rates:

1. **Manual Method**: Run simulations with different ``PACKET_LOSS_RATE`` values and collect join times

2. **Generate Plot**: Run ``generate_all_plots.py`` to create the plot

Analysis Workflow
-----------------

Recommended Workflow
~~~~~~~~~~~~~~~~~~~~

1. **Configure Simulation**
   * Edit ``wsnlab/source/config.py``
   * Set parameters for your scenario

2. **Run Simulation**
   * Run single simulation or batch
   * Wait for completion

3. **Generate Plots**
   * Run ``generate_all_plots.py``
   * Review generated PNG files

4. **Analyze Results**
   * Check CSV files for detailed data
   * Review plots for trends
   * Compare different configurations

Example Analysis
~~~~~~~~~~~~~~~~

Analyzing Join Time Performance:

1. Run simulation:

   .. code-block:: bash

      python3 wsnlab/data_collection_tree.py

2. Check registration log:

   .. code-block:: bash

      head -20 registration_log.csv

3. Generate plots:

   .. code-block:: bash

      python3 generate_all_plots.py

4. Review ``join_time_analysis.png`` for:
   * Distribution of join times
   * Mean and median values
   * CDF showing percentage of nodes joined

Analyzing Energy Consumption:

1. Enable energy model in config:

   .. code-block:: python

      ENABLE_ENERGY_MODEL = True
      ENABLE_ENERGY_DEBUG = True

2. Run simulation and check log file for energy consumption

3. Generate energy plots:
   * ``tx_power_analysis.png``
   * ``network_lifetime.png``
   * ``tx_power_vs_network_lifetime.png``

4. Analyze:
   * Energy per packet
   * Network lifetime estimates
   * TX power impact

Troubleshooting
---------------

Common Issues
~~~~~~~~~~~~~

**Simulation runs too slowly**
   * Set ``SIM_VISUALIZATION = False``
   * Increase ``SIM_TIME_SCALE``
   * Reduce ``SIM_NODE_COUNT``

**No nodes joining network**
   * Check ``NODE_TX_RANGE`` - may be too small
   * Check ``HEARTH_BEAT_TIME_INTERVAL`` - may be too large
   * Enable debug logging to see what's happening

**Too many/few clusters**
   * Adjust ``MAX_CHILD_NODES_ALLOWED_PER_CLUSTER``
   * Lower value = more clusters
   * Higher value = fewer clusters

**Nodes shutting down too quickly**
   * Check ``BATTERY_ENERGY_TOTAL``
   * Reduce ``DATA_PACKET_INTERVAL`` (less frequent packets)
   * Lower ``TX_POWER_DEFAULT`` (less energy per packet)

**No packet paths recorded**
   * Ensure ``DATA_PACKET_INTERVAL`` is set
   * Check that nodes are REGISTERED
   * Verify ROOT node is active

**Plots not generating**
   * Check that CSV files exist
   * Verify CSV files have data (not just headers)
   * Check for error messages in console

Performance Tips
----------------

1. **Disable Visualization**: Set ``SIM_VISUALIZATION = False`` for 10-100x speedup
2. **Reduce Duration**: Use shorter ``SIM_DURATION`` for testing
3. **Fewer Nodes**: Start with smaller ``SIM_NODE_COUNT``
4. **Disable Debug**: Turn off debug flags for production runs
5. **Batch Mode**: Use batch simulations for statistics (runs without visualization)

Advanced Usage
--------------

Custom Analysis Scripts
~~~~~~~~~~~~~~~~~~~~~~~~

You can write custom analysis scripts using the CSV files:

.. code-block:: python

   import csv
   import statistics
   
   # Load join times
   join_times = []
   with open('registration_log.csv', 'r') as f:
       reader = csv.DictReader(f)
       for row in reader:
           join_times.append(float(row['join_delay']))
   
   # Calculate statistics
   print(f"Mean: {statistics.mean(join_times):.2f}s")
   print(f"Median: {statistics.median(join_times):.2f}s")
   print(f"Std Dev: {statistics.stdev(join_times):.2f}s")

Modifying Protocol Behavior
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

To modify protocol behavior:

1. Edit ``wsnlab/data_collection_tree.py``
2. Modify the relevant methods (e.g., ``route_and_forward_package()``)
3. Run simulation to test changes
4. Compare results with original

Adding New Metrics
~~~~~~~~~~~~~~~~~~~

To add new metrics:

1. Add logging in appropriate functions
2. Create CSV file with headers in ``init_log_file()``
3. Write data in logging functions
4. Add plotting function in ``generate_all_plots.py``
